# jdc-recipe-creator

Créer et améliorer les recettes SEO de [journalducuistot.fr](https://journalducuistot.fr) : intro en voix Bertyn, ingrédients quantifiés (unités exactes), étapes ordonnées, ustensiles (affiliation), nutrition par portion, couverture et FAQ — brouillons via le jdc-cms MCP, publication manuelle.

## Fichiers

- `SKILL.md` — le workflow complet (recherche → rédaction → media loop → création → review)
- `references/units-and-nutrition.md` — l'enum des unités (stricte) + la méthode nutrition par portion
- `references/recipe-checklist.md` — checklist champs, schema Recipe, deux passes de review
